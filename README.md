# Emad Galal Portfolio

Static GitHub Pages export of the current portfolio website.

The files at the repository root are the deployable website for GitHub Pages. The editable React source is included under `source/` for reference and future development. Website assets are stored under `manus-storage/` so the public export does not depend on the original hosting environment.

For GitHub Pages, keep the source configured as `main` branch and `/ (root)` folder.
